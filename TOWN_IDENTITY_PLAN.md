# Town Identity Plan

**Status:** essential milestone, not started. Today's 15 towns share one set of building drawings and differ only in layout and palette, which doesn't meet this requirement.

**Goal:** each town is recognisable from its picture alone, feels like a place visited around 1665, and every important building in it does something.

## Rules

- **Function:** each drawn building opens a real interaction. Unbuilt functions aren't drawn yet; background houses, trees and boats are plainly scenery.
- **History:** a landmark is an original illustration that suggests a town's documented character, not a reconstruction of a named building. Dates and claims go in only as far as the sources support them.
- **Religion:** buildings appear only where there's a reason to place them, shown respectfully. Donations are voluntary. Every entry below marked "to verify" needs a source before it's built.
- **Honesty about gaps:** evidence is thin for several towns. Where it is, the town's look is a labelled game interpretation of its setting.
- **No modern forms,** and nothing that treats a community as a threat.

## Acceptance test for each town

A town is only complete when all of these are true:

1. It has at least one drawn landmark no other town uses, and its own building style or material.
2. Its waterfront differs from other towns in form.
3. Its layout is designed for it rather than shared.
4. Every interactive building has a working function, checked by an automated test.
5. It reads at phone and desktop sizes, and a reviewer can tell it apart from the other towns with the name hidden.
6. Its sources and uncertainty are recorded here.

## Build order

1. **Foundations (with Stage 9):** each town gets its own building list and a per-town art module, while the shared drawing kit stays available for ordinary houses.
2. **First five:** Dhaka, Chittagong, Sylhet, Sonargaon, Hooghly, the towns you named. Each must pass the acceptance test before moving on.
3. **Remaining ten:** Kasimbazar, Satgaon, Rajmahal and Patna next, because their histories give the strongest identities, then Tanda, Malda, Balasore, Jessore, Sandwip and Bakla-Chandradwip.

Buildings can't function before their systems exist, so towns gain buildings as Stage 9 delivers them, and art is added at the same time.
